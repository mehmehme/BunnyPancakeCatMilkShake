# 🐰🥞🐱🥤 Bunny Pancake Cat Milk Shake

<p align="center">
  Um jogo casual onde você serve panquecas para coelhinhos e milkshakes para gatinhos. Alimente-os até ficarem fofinhos demais para lidar! 🐇🍰🐾
</p>

## 🎮 Como Jogar

- **Objetivo**: Sirva panquecas para os coelhos e milkshakes para os gatinhos, devolva as bombas para a cozinha.
- **Controle**: Use as setas do teclado.
- **Dica**: Não deixe o tempo acabar ou eles comerem bombas!

## 📦 Requisitos

- Navegador moderno com suporte a HTML5 e JavaScript.
- Nenhuma instalação necessária – apenas abra o arquivo `index.html` no seu navegador.

## 🚀 Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/mehmehme/BunnyPancakeCatMilkShake.git
   ```

🛠️ Tecnologias Usadas

- HTML5

- CSS3

- JavaScript

- Canvas API
